02 / Tech Stack Tools & Architecture Notes

Engineered with proven, high-performance technologies.

Explore tools used in prototypes and research, alongside clearly identified architecture options.

Python Core Language

Primary language for statistical modeling, PyTorch graph neural networks, and asynchronous microservices.

PyTorch Deep Learning

Constructs Two-Tier Relational Graph Convolutional Networks (RGCN) for multi-hop banking fraud detection.

LightGBM Gradient Boosting

Primary gradient boosting engine for calibrated debtor default risk scorecards achieving 0.894 ROC-AUC.

XGBoost Tree Ensembles

Scalable tree boosting for complex non-linear classification and multi-class transaction risk scoring.

Scikit-Learn Classical ML

Foundational toolkit for monotonic feature transformations, pipeline orchestration, and cross-validation.

ONNX Runtime Inference Engine

Runs the documented TrustGraph classifier using paired model and embedding artifacts. Local timings are not banking SLAs.

Pandas & NumPy Tensor Computing

High-throughput vectorized operations, memory-efficient dataframes, and quantitative cohort calculations.

PyTorch Geometric Graph Learning

Relational graph neural networks producing 16-dimensional account embeddings for prototype mule-risk screening.

Apache Kafka Event Streaming

A proposed scaling component in K-NEXUS architecture notes; not established in the documented Application serving path.

Apache Spark Distributed Compute

Distributed cluster framework for large-scale debtor feature extraction and batch temporal aggregation.

PostgreSQL Relational Database

ACID relational database executing idempotent upserts and immutable audit trails for financial transactions.

ClickHouse Columnar OLAP

Ultra-fast columnar analytics powering real-time historical queries across millions of sensor telemetry logs.

Redis In-Memory Cache

A possible caching option in architecture notes. The documented K-NEXUS baseline loads paired model and embedding artifacts locally.

FastAPI Async Microservice

Serves prototype inference, session-bound spending plans, and transfer-review APIs with explicit request schemas.

Docker Containerization

Containerized production microservices ensuring deterministic runtime, process isolation, and smooth CI/CD rollout.

Linux & Bash POSIX Environment

Production server administration, shell automation scripts, systemd daemons, and system telemetry profiling.

Git & GitHub Version Control

Git-flow branching conventions, automated GitHub Actions CI/CD pipelines, and multi-environment deployments.

C++ Systems & Math

Performance-critical computational kernels and embedded firmware architectures designed for zero latency overhead.

TreeSHAP Model Attribution

Exact Shapley feature attributions satisfying Basel III/IV transparency and regulatory adverse action mandates.

OptBinning Scorecard Binning

Monotonic Weight of Evidence (WoE) transformation and Information Value (IV) optimization for credit scoring.

DiCE Recourse Counterfactual XAI

Generates minimum-cost actionable recourse paths showing rejected debtors exact steps required to obtain approval.

Optuna Bayesian Tuning

Bayesian hyperparameter optimization with median pruning across 5-fold stratified financial debtor splits.

MLflow Model Registry

Experiment metric tracking, artifact versioning, and unified model registry powering production staging.
