Enterprise Credit Risk Scoring & Explainable AI (XAI)

Regulatory Framework

In regulated lending, models cannot simply output black-box risk scores. The Equal Credit Opportunity Act (ECOA) and Basel Framework mandate automated adverse action reason codes for rejected or subprime loan applicants.

Explainable AI (XAI) Solution

Bridges gradient boosted trees (LightGBM/XGBoost) with SHAP TreeExplainer and LIME local surrogate models to produce accurate Probability of Default (PD) scoring alongside instant, audit-ready explanations.

Raw Loan Data
WoE / IV Binning
LightGBM Model
SHAP Waterfall
FastAPI Serving

Weight of Evidence (WoE)

Continuous features are discretized into monotonic risk bins. Ensures linear relationship with log-odds of default while naturally handling missing values and non-linear trends.

Information Value (IV) Filter

Filters out weak predictive variables with \(\text{IV} < 0.02\), retaining medium-to-strong drivers (DTI, revolving utilization, past-due counts) to eliminate multi-collinearity.

SMOTE-Tomek Sampling

Addresses severe class imbalance (1:12 default ratio) using SMOTE synthetic minority oversampling paired with Tomek link cleaning to sharpen class decision boundaries.

1. Data Generation & Ingestion

Python-based multi-machine telemetry simulator generating high-frequency industrial machine metrics (temperature, vibration, cycle time, operational states, and fault codes).

2. Infrastructure & Storage

Containerized PostgreSQL database configured via Docker Compose with B-tree and composite indexing optimized for high-throughput time-series sensor logs and audit execution tables.

3. Processing & Analytics

Automated batch ETL jobs computing rolling machine availability, performance ratios, and quality rates to derive real-time Overall Equipment Effectiveness (OEE).

Overall Equipment Effectiveness (OEE)
Computed dynamically as \(\text{Availability} \times \text{Performance} \times \text{Quality}\) across rolling shift windows.
Rolling Metrics Aggregation
Computes continuous equipment availability ratios, micro-stoppage counts, and unit defect rates per production line.
Stateful Anomaly Detection
Automated monitor continuously evaluates thermal and vibration bounds, logging operational excursions into audit tables.

Provides drill-down visibility into live factory floor performance, downtime root causes, and pipeline health logs.
