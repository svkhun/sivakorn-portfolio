Long Overdue Debtor Prediction

A competition machine-learning pipeline for predicting 12-month long-overdue borrowers. The work focuses on financial feature engineering, validation under class imbalance, and CatBoost/LightGBM blending.

View Source Code Back to Directory
“For a rare default outcome, the evaluation method and the meaning of each financial feature matter as much as the model choice.”
01 // Competition Problem

Rank long-overdue risk from credit records

The competition target was whether a borrower would become long overdue within 12 months. Positive cases were a minority, so simple accuracy could conceal weak risk ranking.

The team built features such as debt-to-income burden, credit utilization, unused credit headroom, working stability, and product-level balances. Missingness indicators and skew-aware transforms preserved information in imperfect records.

02 // Modeling Process

Validate before blending

CatBoost and LightGBM experiments were compared using stratified out-of-fold predictions. The team explored probability and rank blending, regularization, and financial-ratio features rather than reporting a single training-set score.

The public repository reports the following out-of-fold ROC-AUC experiments. They are model-development results, not a measured collections or recovery outcome.

03 // Evidence & Data Boundaries

What can be inspected publicly

The source repository includes preprocessing, model-training and blending code, plus a synthetic fallback dataset so the workflow can be tried without exposing competition records. Raw financial data is confidential and is not published.

National-finalist status describes the competition outcome. The project does not establish actual debt recovered, collection-agent productivity, or a deployed lending decision service.
